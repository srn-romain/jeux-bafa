Assistant IA (Gemini)

Clé personnelle requise pour l'assistant intelligent dans vos espaces.

Comment obtenir cette clé gratuitement ?
  1. Rendez-vous sur Google AI Studio.
  2. Connectez-vous avec votre compte Google (Gmail).
  3. Cliquez sur "Get API key" dans le menu à gauche.
  4. Cliquez sur le bouton bleu "Create API key".
  5. Copiez le code (il commence par AIzaSy...) et collez-la ici.

Note : Ne partagez jamais cette clé avec des personnes non autorisées.
