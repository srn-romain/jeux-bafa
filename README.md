# Répertoire Colo

Site de ressources pour les animateurs et directeurs de colonies de vacances : activités, jeux, veillées, réglementation et documents de formation BAFA/BAFD.

## Utilisation

Ouvrez `index.html` dans un navigateur. Le site est statique et ne nécessite pas d'installation de dépendances.

## Déploiement

L'hébergement est configuré avec Firebase.
